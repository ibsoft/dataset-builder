# Changelog

## 1.0.0 — 2026-11-09

First release: Flask-based multi-user UTF-8 Markdown editor with Greek/English user preferences, independent structured/raw modes, live safe preview, unlimited solutions, instant revision history, created/updated attribution, optimistic concurrency, administration, soft delete and restore, import CLI, zipped versioned export, PostgreSQL and SQLite support, and container deployment. Subsequent releases should use changed-files-only patch ZIPs as defined in `README.md`.
